# Introduction to Spring MVC and Thymeleaf

👉 **Access the online course**:

## Overview

The purpose of this document is to introduce, through examples, the fundamental concepts of **Spring MVC**, a Java web framework based on the **MVC (Model–View–Controller)** pattern.

Spring MVC is part of the **Spring Framework** ecosystem and provides a structured framework for developing robust and maintainable Java web applications.

The course also introduces **Thymeleaf**, a modern and powerful view engine that integrates particularly well with Spring MVC.

## Target Audience

This course is intended for readers with a **good command of the Java language**.

**No prior knowledge of web programming is required**, as concepts are introduced gradually.

## Scope of the Document

Although relatively detailed, this document does not claim to be exhaustive.
Spring is a vast framework, composed of numerous components and extensions.

The document was designed to be **read without a computer**, which explains the presence of numerous **screenshots**.
